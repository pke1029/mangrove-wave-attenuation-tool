# Mangrove Wave Attenuation Tool

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://mangrove-wave-attenuation-tool.streamlit.app/)

Estimate how much a mangrove belt attenuates an incoming wave, from root structure and local water conditions. The wave attenuation model is based on the work by Pang and Tay (https://arxiv.org/abs/2606.11653).

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
